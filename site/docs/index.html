Documentation

svelteMyAdmin is configured like phpMyAdmin: the same $cfg keys, written as JSON. This overview covers installing and running it. The guides cover features that need setup.

Single sign-onLog people in through oauth2-proxy or another SSO proxy, no MySQL passwords. On Kubernetes: RBAC per namespace and discovered review databases. Audit logRecord who did what, when and from where, per person, as JSON lines.

Install and run

Requires Node.js 22 or newer and pnpm.

pnpm install
cp config.sample.json config.json
pnpm build
SMA_CONFIG=/path/to/config.json node build

For development, pnpm db:up starts demo MySQL 8.4 and MariaDB 11.4 servers with Docker (root / root), then pnpm dev runs the app.

Configuration file

The app reads config.json from its working directory, or the path in SMA_CONFIG. Key names and defaults mirror phpMyAdmin's config.default.php, so an existing config.inc.php translates almost line by line. One difference: Servers is a JSON array, while ServerDefault stays 1-based. 

{
	"blowfish_secret": "32 random characters or more",
	"Servers": [
		{ "verbose": "Local MySQL", "host": "127.0.0.1", "port": 3306, "auth_type": "cookie" }
	]
}

Authentication types

Each server picks how people log in with auth_type.

auth_type Who logs in
cookie Login form with a MySQL user and password. The default. Supports two-factor authentication.
config No login. The app uses the server's user / password.
http HTTP Basic authentication with a MySQL user and password.
signon An SSO proxy identifies the person. See Single sign-on.
